# État de la validation à l'exécution

> Traduction de la [page originale en anglais](../../../status/runtime-validation-status.md) d’OmsiLaunch 0.1.0-beta4. La page anglaise fait foi : en cas de divergence, la page anglaise et le code prévalent.

Cette page est l'unique tableau de preuves d'OmsiLaunch 0.1.0-beta4. Chaque ligne nomme une capacité ou une fonctionnalité et l'état de ses preuves. `RUNTIME_VALIDATED` peut citer soit `research/reports/OMSILAUNCH-RUNTIME-VALIDATION-MATRIX.md` (identifiants de matrice RV-nnn, blocages BI-nnn, identifiants de session issus de son tableau d'exécution du 2026-09-20), soit le rapport post-Fable Round A `research/reports/OMSILAUNCH-RUNTIME-VALIDATION-ROUND-A-001.md` (RA-nnn) ; tout le reste est déduit du code et des suites de tests hors ligne. La campagne de durcissement du 2026-09-21 (`research/reports/OMSILAUNCH-SECURITY-ROBUSTNESS-REVIEW-001.md`, constats S-01 à S-34) a modifié le comportement de la restauration, de la récupération, du plan de contrôle et des frontières ; ces modifications ne disposaient que de preuves hors ligne. La campagne finale de clôture runtime du 2026-09-23 (`research/reports/runtime-closure/FINAL-RUNTIME-VALIDATION-REPORT.md`, identifiants de scénario tels que `F01`, `S05`, `T01`, candidats 2 et 3) les a exécutées dans des sessions réelles sur l'installation autorisée ; les lignes promues par cette campagne citent ses identifiants de scénario et de session. `RUNTIME_VALIDATED` peut donc également citer ce rapport.

États des preuves :

| État | Signification |
| --- | --- |
| RUNTIME_VALIDATED | Observé dans une session canonique enregistrée dans la matrice (identifiant et session cités). |
| STATICALLY_VALIDATED | Implémenté et couvert par des tests hors ligne (`tools/OmsiLaunch.TestHost`, `tests/*`), non observé dans une session réelle depuis la dernière modification. |
| PARTIAL | Implémenté, mais les preuves sont incomplètes ou contredites, ou le comportement est connu pour être limité. |
| RUNTIME_VALIDATION_REQUIRED | Comportement modifié ou jamais observé ; doit être validé dans une session réelle avant de pouvoir être promu. |
| UNAVAILABLE | Non implémenté ou délibérément rejeté. |
