# Статус проверки в runtime

> Перевод [исходной страницы на английском языке](../../../status/runtime-validation-status.md) для OmsiLaunch 0.1.0-beta4. Нормативной является английская страница: при расхождениях приоритет имеют английская страница и код.

Эта страница — единая таблица подтверждений для OmsiLaunch 0.1.0-beta4. В каждой строке указаны возможность или функция и состояние её подтверждения. Для `RUNTIME_VALIDATED` может приводиться ссылка либо на `research/reports/OMSILAUNCH-RUNTIME-VALIDATION-MATRIX.md` (идентификаторы матрицы RV-nnn, блокеры BI-nnn, идентификаторы сеансов из её таблицы выполнения от 2026-09-20), либо на отчёт Round A после Fable `research/reports/OMSILAUNCH-RUNTIME-VALIDATION-ROUND-A-001.md` (RA-nnn); всё остальное выведено из кода и наборов офлайн-тестов. Раунд усиления защиты от 2026-09-21 (`research/reports/OMSILAUNCH-SECURITY-ROBUSTNESS-REVIEW-001.md`, находки с S-01 по S-34) изменил поведение восстановления, восстановления после сбоя (recovery), плоскости управления и границ; для этих изменений были только офлайн-подтверждения. Финальный раунд закрытия проверки в runtime от 2026-09-23 (`research/reports/runtime-closure/FINAL-RUNTIME-VALIDATION-REPORT.md`, идентификаторы сценариев, например `F01`, `S05`, `T01`, кандидаты 2 и 3) выполнил их в реальных сеансах на авторизованной установке; строки, повышенные в этом раунде, ссылаются на его идентификаторы сценариев и сеансов. Поэтому `RUNTIME_VALIDATED` может ссылаться и на этот отчёт.

Состояния подтверждения:

| Состояние | Значение |
| --- | --- |
| RUNTIME_VALIDATED | Наблюдалось в каноническом сеансе, записанном в матрице (указаны идентификатор и сеанс). |
| STATICALLY_VALIDATED | Реализовано и покрыто офлайн-тестами (`tools/OmsiLaunch.TestHost`, `tests/*`), после последнего изменения в живом сеансе не наблюдалось. |
| PARTIAL | Реализовано, но подтверждения неполны или противоречивы, либо поведение заведомо ограничено. |
| RUNTIME_VALIDATION_REQUIRED | Поведение изменилось или никогда не наблюдалось; перед повышением статуса должно быть проверено в реальном сеансе. |
| UNAVAILABLE | Не реализовано или намеренно отклонено. |

## Сводный список RUNTIME_VALIDATION_REQUIRED

Раунд закрытия проверки в runtime от 2026-09-23 закрыл предыдущую очередь. Она остаётся пустой, за исключением пунктов, которые невозможно безопасно воспроизвести на этой установке:

1. Игровой процесс, чтение, команды и остановка для Steam LAA: требуется подлинная установка Steam (окружение; строка выше имеет статус `PARTIAL`).
2. Удаление RoadVehicle и Human для RV-002: нет безопасного способа воспроизвести удаление (строка выше имеет статус `PARTIAL`).

Пункты, которые остаются проверенными только офлайн-тестами, поскольку их невозможно воспроизвести извне продукта, отмечены в своих строках и не входят в очередь: повреждение ответа в почтовом ящике, слишком большие ответы, усечение истории событий, переход D3D `lost`, выход из системы, коды выхода shim 100-106 и ветвь отложенного восстановления без отпечатка.
